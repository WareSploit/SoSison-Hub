# Feature migration checklist
Inventory based on the supplied `ww2.lua`. This is a coverage checklist, not a claim that all features are implemented. Each item is ported and tested separately.

## Sheriff
- [ ] Gun settings and custom gun sounds
- [ ] Aim / silent aim / aimbot settings (UI inventory only; no attack automation)
- [ ] Target selection and FOV controls
- [ ] Sheriff role utilities

## Murderer
- [ ] Knife settings and appearance
- [ ] Target selection and murder settings (no kill automation)
- [ ] Knife throw settings (no exploit/remote abuse)

## Player
- [ ] Movement settings and character options
- [ ] Anti-aim settings (UI inventory only)
- [ ] Protection and local quality-of-life options

## Visuals
- [ ] ESP: players, roles, names, boxes, tracers and settings
- [ ] World / lighting; weather and sky
- [ ] Effects, auras and particles
- [ ] Skins, looks and visual presets
- [ ] Custom cursor and screen options

## Farm
- [ ] Coin collection settings (no unattended exploit automation)
- [ ] Role options and boxes
- [ ] Webhook configuration and trade UI

## Teleport
- [ ] Player list and teleport UI
- [ ] Role and map/location destinations

## Troll
- [ ] Fling menu inventory (no disruptive action implementation)
- [ ] Toys, emotes, fun options and effects

## Animations
- [ ] Bundles; emote catalog and options; skins; favorites

## Music
- [ ] Boombox; game/custom sounds; SoundCloud player UI

## Chat / SoSison Users
- [ ] Messages and community chat UI
- [ ] Community/server discovery UI

## Mobile
- [ ] Touch controls and on-screen buttons

## Config Hub
- [ ] Browse, import and export configs

## Settings
- [ ] UI scale, size, opacity, keybind, sounds and tooltips
- [ ] Config management; performance/optimizer; about/version

## Server
- [ ] Server info and job ID
- [ ] Rejoin and legitimate server navigation controls
