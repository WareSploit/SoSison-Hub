## WindUI
Selected framework: `Footagesus/WindUI` (MIT).
Official source: https://github.com/Footagesus/WindUI
Documentation: https://footagesus.github.io/treehub-web/docs/windui

Reason: broad controls, themes, responsive/mobile UI, notifications, dialogs and config persistence. Upstream currently marks the project beta; pin and test a known-good version before release. Avoid unofficial reuploads.
